## 2. 先写清“窗口、统计量、答案”各自是什么

| 题目 | `[left, right]` 代表什么 | 维护的主要信息 | 最终返回什么 |
| --- | --- | --- | --- |
| 1208 | 准备在同下标转换的片段 | 窗口内修改费用和 | 最长合法长度 |
| 424 基础版 | 准备改成相同字母的片段 | 窗口内频次与真实最高频次 | 最长可修改长度 |
| 1695 | 选中删除并获得分数的片段 | 窗口内频次与元素和 | 最大总和 |
| 1234 | 准备替换的片段 | **窗口外**四种字符数量 | **窗口本身**的最短长度 |
| 1658 | 两端删除之后保留的片段 | 保留部分的和 | `n - 最长保留长度` |
| 713 | 固定右端下最靠左的合法片段 | 窗口乘积 | 所有合法子数组的数量 |

1234 的 `outside` 不是一个位置，也不是答案所在区域。它只是计数表，用不能改的部分判断能改的部分是否足够。窗口外既可能有左边的前缀，也可能有右边的后缀。

1658 则是先把原题转换成另一个目标再使用窗口：找到最长保留长度后，还必须回到原题，换算成删除次数。变量名或窗口长度本身并不能决定题目要返回什么。

## 3. 窗口成立后，答案不只有一种更新方式

| 目标 | 什么时候记录 | 记录内容 |
| --- | --- | --- |
| 最长合法片段：1208、424 基础版 | 非法时收缩，恢复合法后 | 与 `right - left + 1` 取最大值 |
| 最大合法总和：1695 | 恢复无重复后 | 与窗口和取最大值 |
| 最短可替换片段：1234 | 仍然可行时，先记录再尝试收缩 | 与窗口长度取最小值 |
| 和恰好等于目标：1658 | 收缩到不超标后，再检查是否相等 | 相等时记录最长保留长度 |
| 定长候选计数：1343 | 完整的长度为 `k` 的窗口达标时 | 每次加一 |
| 全部合法子数组计数：713 | 固定右端，得到最左合法起点后 | 每次加 `right - left + 1` |

713 的加法不是在循环里逐个列出所有子数组：合法起点恰好是 `left ... right`，可以直接计算它们的数量。每个子数组只在自己的右端点那一轮计入，因此没有重复。若一轮重新统计窗口内的所有子数组，会把之前已经结束的那些片段再次计入。

这个公式依赖本题的性质：全部元素至少为 `1`，合法窗口去掉左端若干因子后仍合法。不能把“窗口长度就是新增数量”机械套到任意计数题。

## 4. 初始化与访问顺序，要服从同一套区间定义

两种边界都能使用，但不能混用：

| 区间 | `right` 的含义 | 长度 |
| --- | --- | --- |
| `[left, right]` | 已加入的最后一个位置 | `right - left + 1` |
| `[left, right)` | 下一次准备加入或第一个未包含的位置 | `right - left` |

1208 的旧结构在循环末尾先移动右端，再加入费用，初始 `sum` 必须对应 `[0,0]`；后来只把 `sum` 改成零，就漏掉了下标 `0`。若采用“本轮先加入当前右端”的组织方式，初始才应使用空窗口的和 `0`。

713 同理：空窗口的乘积从 `1` 开始。想让右端停在最后一个合法位置，应先检查下一位是否存在、加入后是否合法；不能只检查当前乘积就移动下标。循环入口检查通过，也不能保护自增之后的数组访问。

1234 初始统计整串字符到 `outside`，对应的是空的待替换窗口。字符进入窗口时，外部数量减一；离开窗口时，外部数量加一。若改成一开始选中整个字符串，外部就应为空，后续遍历也需要一起设计。

## 5. 为什么内层可以走多次，总体仍然是线性

只要每次状态更新是常数工作，并且两个指针都只前进、不回头：

```text
所有轮次的 right 移动次数之和 <= n
所有轮次的 left 移动次数之和  <= n
总时间 O(n)
```

某一轮集中移动很多次左端，不代表每一轮都要重走这些位置。真正导致重复工作的是：每换一个起点，都重置另一端和统计量，从头重新扫描重叠片段。

713 中全是 `1`、`k = 2` 时，固定每个左端并从头扫描要处理 `n + (n-1) + ... + 1` 个位置；复用窗口只需加入 `n` 次元素，用 `n` 次加法得到同样多的子数组数量。**结果数量可以是平方级，计算数量的工作量仍可以是线性。** 如果要求把每个子数组实际列出，就又是另一种输出规模。

外层用 `for` 还是 `while`、固定左端还是固定右端，都不是复杂度的根本区别。要看边界和状态是否持续保留、是否反复处理同一批数据。

## 6. 不能省略的适用条件与例外

- **定长窗口**：相邻窗口的和可以减去移出值、加上移入值，即使含负数也成立。
- **1208 的预算窗口**：费用非负，扩大不能让超预算片段重新合法，因此被排除的左端点无需回头。
- **1695 的最大和与 1658 的精确目标和**：本题全为正数，是“最长合法后缀具有最大和”或“超标就收缩”的依据。允许负数后需要重新推导。
- **713 的乘积窗口**：元素至少为 `1`，乘积的变化允许排除左端并批量计数；含零或负数时，这套判定与除出操作不能直接照搬。
- **424 的历史最高频次版本**：它保存的最大频次可以过时，维护的当前窗口也可能不真实合法。该优化保证的是最大长度，不是每个窗口都能直接作为方案返回，具体证明保留在题目笔记中。

复习时先说明状态的含义和可排除候选的理由，再写移动方向、判断条件与答案更新，才能区分这些看起来相似的循环。
