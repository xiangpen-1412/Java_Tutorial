## 2. HashMap：从“向后寻找”改成“查询已知信息”

### Two Sum

遍历到 `current` 时，需要的另一个数是：

```text
need = target - current
```

暴力解法每次向后扫描；HashMap 把已经见过的值及下标保存起来，使查询平均为 `O(1)`。

识别信号：

```text
找两个元素满足某种对应关系
需要返回原下标
数组没有可利用的有序性
```

### Group Anagrams

这题不是查补数，而是用 HashMap 分组：

```text
key   = 字符串的标准形式
value = 具有相同标准形式的字符串列表
```

标准形式可以来自排序结果或字符频率。真正的模式是：

> 先为每个对象提取能代表所属类别的 key，再按照 key 放入不同桶中。

## 3. 两类双指针必须分清

### 相向双指针

```text
left  →       ← right
```

适用于从两端比较，或者利用有序性排除答案。

当前题目：

```text
125：比较左右有效字符
167：根据当前和的大小移动一侧
15：固定一个数后，在剩余有序区间找两数和
```

### 同向读写指针

```text
write →
read  →→→
```

`read` 负责扫描，`write` 表示下一个有效元素应写入的位置。

当前题目：

```text
283：读到非零元素就写入前部，最后补零
26：读到与上一个有效值不同的元素才写入
```

这类题的重点不是“删除数组元素”，而是维护一个有效前缀：

```text
nums[0 ... write - 1] 始终是已经处理好的答案区域
```

## 4. 滑动窗口：维护一个连续区间

先确定题目研究的是连续子数组 / 子串，再判断窗口长度是固定的，还是需要根据条件变化。

### 可变长度：通过收缩恢复合法

[[03-3-Longest Substring Without Repeating Characters]] 研究的是连续子串，而不是任意选择字符。它维护的条件是“没有重复字符”，窗口长度可以变化。

完成调整后：

```text
[left, right] = 当前仍满足条件的连续区间
```

处理顺序：

```text
right 加入新元素
如果窗口违反条件，移动 left 恢复合法
合法后更新答案
```

这一类窗口需要判断：右端扩张后，能否通过移动左端恢复条件；不是所有连续区间问题都适用。

### 计数窗口：先定义统计对象，再确定 while 和加法

“超标时收缩”并非所有窗口的唯一写法。至多类计数恢复合法后，固定当前右端，统计 `left ... right` 这些合法起点，增加 `right - left + 1`；它不是整个窗口内部所有子数组的数量。

1358、2962 的直接覆盖计数则在原题达标时，一次计入当前起点的全部合法终点 `right ... n-1`，增加 `n-right`，随后可以移走已经处理完的起点。若希望继续用至多窗口，先转换目标：恰好 K 为两次至多之差，至少 K 可以用总数减至多 K-1。1358 只含三种字符，所以“包含全部三种”又等价于“恰好三种”，即总数减最多两种。

详细反例和推导见 [[Sliding Window Problems Summary]]；不能只根据“求子数组数量”选择公式。

### 固定长度：复用相邻窗口的重叠部分

[[09-643-Maximum Average Subarray I]] 要求长度恰好为 `k`。每次移动都移出一个元素、加入一个元素，长度保持不变：

```text
新窗口和 = 旧窗口和 - 移出元素 + 加入元素
right 是新加入的下标 → 移出下标为 right - k
```

应先明确 `sum` 对应的区间，再写更新下标。如果沿用“上一轮末尾已经执行 `left++`”的结构，此时移出的应为 `nums[left - 1]`，不能移出仍在新窗口里的 `nums[left]`。

所有候选窗口的分母都是同一个正数 `k`，所以只需比较总和，最后一次浮点除法得到平均值。第一个窗口完整求和，以后每次 `O(1)` 更新，总时间 `O(n)`、额外空间 `O(1)`。允许负数不影响这个更新等式；若窗口长度变化，就不能直接用最大总和代替最大平均值。

[[10-1343-Number of Sub-arrays of Size K and Average Greater than or Equal to Threshold]] 复用同一套窗口移动方式，但目标改为统计达标窗口数。因为 `k > 0`，平均值大于等于 `threshold` 等价于 `sum >= k * threshold`，无需实际计算平均值。先检查第一个窗口，之后每次移出、加入完成后再检查，总共覆盖 `n - k + 1` 个窗口。窗口不达标时也保持长度为 `k`，继续向右移动。

### 窗口最值：候选下标与双端队列

[[23-239-Sliding Window Maximum]] 同样是定长窗口，但最大值移出时不能像和一样直接减掉；需要保留还能成为答案的候选。单调队列按下标先后存储候选，队首剔除过期位置，队尾移除不大于新值的旧候选。新值至少一样大且更晚过期，因此被淘汰的旧候选无需恢复。

队列保存的是候选集合，不是完整窗口；删除候选也不等于移动 left。每个下标入队、出队至多一次，时间 O(n)，额外空间 O(k)。定长 / 可变描述的是区间怎样变化，单调队列描述的是怎样维护最值，两者可以组合。

## 5. 排序的作用不只是让结果有序

[[06-15-3Sum]] 中排序提供三种能力：

1. 可以根据和的大小决定移动哪一侧；
2. 相同元素相邻，方便跳过重复答案；
3. 固定一个数后，把三数问题降为标准两数问题。

去重必须发生在产生重复选择的位置：

```text
固定点重复 → 跳过重复固定点
找到答案后 → 跳过左右两端的重复值
```

## 6. 一张选择方法的判断表

| 题目信号 | 优先考虑 |
| --- | --- |
| 无序数组中快速找对应值 | HashMap |
| 按共同特征把元素分组 | 标准化 key + HashMap |
| 有序数组中找两数关系 | 相向双指针 |
| 从两端比较字符或元素 | 相向双指针 |
| 原地删除、搬移、保留有效元素 | 读写指针 |
| 连续区间长度固定，相邻窗口可复用统计量 | 固定长度滑动窗口 |
| 最长/最短连续子串，窗口能逐步恢复合法 | 可变长度滑动窗口 |
| 多次查询不变数组的区间和 | 前缀和数组 |
| 区间条件可转为两个前缀之间的匹配关系 | 前缀状态 + 历史位置或次数 |
| 三数和且要求去重 | 排序 + 固定一点 + 双指针 |

## 7. 当前题目中常见错误

```text
看到数组就只想到 for 循环，没有先看“有序、连续、原地”等性质；
读写指针中混淆“当前读取位置”和“下一个写入位置”；
滑动窗口遇到冲突后只移动一次 left，没有持续恢复合法；
固定窗口先移动 left 后，移出 nums[left]，误删新窗口中的元素；
用 (double) (sum / k) 计算平均值，转换前整数除法已丢掉小数；
3Sum 只对最后结果 distinct，没有在选择阶段去重；
Two Sum 排序后忘记题目要求原始下标；
Group Anagrams 的 key 不能稳定代表同一类别。
```

整数除法转换时机的通用规则见 [[10-Integer Division & Double Keys]]。最大值来自实际候选窗口时，还要用第一个窗口初始化，避免全负数时错误地保留 `0`。

## 8. 记忆主线

```text
无序查对应值      → HashMap
有序两端可排除    → 相向双指针
原地压缩有效区域  → 读写指针
连续区间长度固定  → 移出一个、加入一个，复用窗口统计量
连续区间按条件变化 → 定义原题或辅助条件，再决定收缩与答案更新
多个元素组合      → 固定一个点，把问题降级
对象需要分类      → 提取统一 key 后分组
```
